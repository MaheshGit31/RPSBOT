# RPSBOT

A rock-paper-scissors machine built with no microcontroller and, no firmware.

## Parts List

**4 BUTTONS**

**1. Clock — NE555 (U1)**

**2. Counter — CD4017 (U2)**

**3. Latches — 74HC02 NOR gates (U3, U4)**

**4. Comparator — 74HC08 AND + 74HC32 OR (U5–U9)**

(P = your pick, C = the computer's pick, r/p/s = rock/paper/scissors)


## Files

- `rps_logic.kicad_sch` / `rps_logic.kicad_pro` — schematic
- `rps_logic.kicad_pcb` — routed PCB
